# Yandex Music visualizer backup

Сохранённая копия WebGL-эффекта «Моей волны» из Yandex Music.

| Файл | Описание |
|------|----------|
| `vibe-visualizer.yandex.js` | WebGL рендерер |
| `vibe-shaders.yandex.js` | GLSL шейдеры |

Чтобы вернуть эффект, скопируйте файлы обратно в `js/` и подключите `VibeVisualizer` в `app.js`.
